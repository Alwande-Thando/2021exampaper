# Question 3 – Snake Bite Information

Swing GUI that reads snake names and details from `snakes.txt` at startup. The combo
box is populated from the file; Submit displays the selected snake's fatality ranking
and medical-assistance timing in the list; Clear empties the list.

The included `snakes.txt` reproduces the three entries visible in the exam's sample:
Black Mamba, Boomslang and Puff Adder. The timings/rankings are reproduced as exam
sample data, not presented as medical advice. In a real snakebite emergency, seek
emergency medical assistance immediately and do not wait for a displayed time estimate.
