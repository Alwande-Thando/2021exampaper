# PROG6112 2021 – Java Reference Solutions

Three separate Java 17 Maven projects are included:

1. **Q1_MusicalLessons** – Swing GUI for instrument/level selection, lesson cost,
   average lesson cost report and menu actions.
2. **Q2_MotorbikeSales** – 2D sales array, quarterly amounts, totals and Gold/Silver
   classification.
3. **Q3_SnakeBiteInformation** – Swing GUI that loads snake names and details from
   `snakes.txt` and displays the selected record.

## Running
Open each question folder separately in IntelliJ IDEA or NetBeans as a Maven project.
Run the main class shown in that question's README. For Q3, keep `snakes.txt` in the
application working directory so it can be read at startup.

The snake information is copied from the sample text file shown on page 10 of the
exam paper. It is exam data, not medical guidance. All three projects' main source
files were checked for Java compilation. JUnit tests are included but were not run
in this environment.
